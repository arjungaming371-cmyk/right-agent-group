📞 QUICK TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────
Voice Bot not responding?
  → Check Exotel API key (should be aiagent25 credentials)
  → Verify STT service (port 3003) and TTS service (port 3004)
  → See STATUS_REPORT.md → "VOICE BOT" section

WhatsApp not sending?
  → Check WHATSAPP_TOKEN (expires ~23h)
  → Verify webhook is reachable (tunnel active?)
  → See STATUS_REPORT.md → "WHATSAPP" section

Developer can't login?
  → Verify email in allowed_emails table with role='developer'
  → Clear browser cookies
  → Try incognito mode

Status indicators not updating?
  → Refresh page (F5)
  → Check browser console (F12)
  → Verify /api/system/status endpoint
